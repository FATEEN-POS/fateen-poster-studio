# 🧡 استوديو بوسترات فطين

أداة ويب بتجهّز **بوسترات ستاند الكاشير الذكي** في دقايق: تختار نوع النشاط والبوستر، تكتب بياناتك، تشوفه على ستاند ثلاثي الأبعاد، وتنزّل **ورقة طباعة PDF** جاهزة.

🏠 **موقع فطين:** [fateen1.me](https://fateen1.me)

## ✨ المميزات

- **٤ أنواع أنشطة جاهزة:** كافيه / مطعم، عيادة / مركز، محل / متجر، صالون / جيم، وكل نوع بيرشّح لك ٣ بوسترات مناسبة.
- **٣ بوسترات لكل مكان:** بوستر لكل ستاند، ومجموعة ألوان متناسقة بين الثلاثة.
- **أنواع البوسترات:** المنيو الرقمي، تقييم جوجل، تابعنا، دفع إلكتروني، الواي فاي، رأيك يهمنا، واتساب، حجز، عرض.
- **تصميمين:** «لمعة» و«كلاسيك».
- **ألوان جاهزة** (برتقالي فطين، نيون، ذهبي، أزرق ملكي، بنفسجي، زمردي، مرجاني، نعناعي، أسود وأبيض) **أو لونين من اختيارك** للخلفية والتمييز.
- **اسم مكانك + لوجو** (اختياري) وتعديل نصوص كل بوستر.
- **QR Code متولّد جوّه الصفحة** للّينك اللي تحطه، وبوستر الواي فاي بيتعمل له QR اتصال مباشر.
- **مكان NFC ثابت** في نفس الموضع على كل بوستر، علشان الاستيكر يتركّب صح على الستاند.
- **معاينة ثلاثية الأبعاد** للستاند: من قدّام، بزاوية، من ورا، مع تقريب وتبعيد، وعرض تلقائي، وعرض كل ستاند لوحده.
- **معاينة في صورة حقيقية** لثلاث ستاندات.
- **ورقة طباعة PDF بمقاس A4:** البوسترات بمقاس **١٠ × ١٥٫٢ سم** مع علامات قص. اطبعها بحجم فعلي **١٠٠٪**.
- **حفظ تلقائي** لاختياراتك في المتصفح، فلو قفلت الصفحة ترجع تكمّل من مكانك.
- **طلب سريع على واتساب** للتواصل مع فطين.

## 🚀 طريقة الاستخدام

1. **اختار** نوع نشاطك، وبعدها نوع كل بوستر والتصميم والألوان.
2. **اكتب** اسم مكانك، وارفع اللوجو لو عايز، وحط اللينكات المطلوبة (المنيو، التقييم، الدفع…).
3. **شوفه** على الستاند في المعاينة.
4. **نزّل** ورقة الطباعة PDF واطبعها من أي مكتبة.

## 🛠️ التشغيل محليًا

المشروع **ملف HTML واحد**: مفيش build ولا dependencies ولا سيرفر.

```bash
git clone https://github.com/<your-org>/fateen-poster-studio.git
cd fateen-poster-studio
# افتح الملف في المتصفح
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

> الخطوط (IBM Plex Sans Arabic وIBM Plex Sans وIBM Plex Mono) بتتحمّل من Google Fonts، فمحتاج إنترنت أول مرة علشان الشكل يطلع مظبوط.

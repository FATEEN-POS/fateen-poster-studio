# fateen-poster-studio
استوديو بوسترات فطين: أداة ويب بتجهّز بوسترات ستاند الكاشير الذكي. اختار نوع النشاط والبوستر (منيو، تقييم جوجل، دفع، واي فاي، واتساب، حجز)، ضيف اسم مكانك ولوجو، وشوفه على ستاند ثلاثي الأبعاد. كل بوستر فيه QR ومكان ثابت لـ NFC، وتنزّل PDF جاهز للطباعة بمقاس 10×15.2 سم بعلامات قص. ملف HTML واحد من غير build.
